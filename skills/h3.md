# MiniMax H3 — structured video+audio prompt rewriting

**Model:** `minimax_h3_ref2va_pruned_nvfp4` / `..._int8_convrot`
**Text encoder:** Qwen3-VL-32B (type `minimax`)
**Output:** up to 2K, 24fps, ~15s, with **native stereo audio** — voice, sound
effects and music generated jointly in one forward pass.

H3 is **not** prompted like other video models. It consumes a structured,
labelled rewrite with fixed field names and a fixed section order. Getting the
field names or ordering wrong measurably degrades output. The authoritative
rules are supplied alongside this file as a reference guide — follow that guide
exactly, and treat this file as the operating procedure around it.

## Which guide applies

| Mode | Meaning | Guide | Sections |
|---|---|---|---|
| **T2VA** | text → video+audio | base | 3 |
| **I2VA** | first frame → video+audio | base | 3 + first-frame instruction |
| **FL2VA** | first + last frame | base | 3 + alignment instruction |
| **L2VA** | last frame only | base | 3 + alignment instruction |
| **Ref2VA** | full reference (subjects / video / audio) | full-reference | 6 |

The three-section modes emit, in this order and with these exact names:

```
integrated_multimodal_description:
overall_soundscape:
non_diegetic_music:
```

Full-reference mode emits, in this order and with these exact names:

```
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

## Output format

Emit **only** the required sections, in order, as plain text. No markdown
headings, no code fences, no commentary before or after. Field names are written
exactly as shown above, lowercase with underscores, each followed by a colon.

For the modes that require a leading alignment instruction (I2VA, FL2VA, L2VA),
that instruction is the **first line of the output**, followed by one blank
line, then the fields.

## Non-negotiables

- **Write every section in English.** The only exceptions are dialogue and
  lyrics inside `<d>…</d>` and text visibly present in the scene inside double
  quotes — those keep their original language, wording, and punctuation verbatim.
- **Timing must match the requested duration.** Cut times are strictly
  increasing, formatted `[Shot N] At MM:SS.mmm,`, and every one falls inside the
  duration. Alignment instructions use exactly two decimal places (`8.00`).
- **`[Shot 1]` never carries a timestamp.**
- **Every reference label must resolve.** A `<Subject N>`, `<Picture N>`,
  `<Video N>` or `<Audio N>` used anywhere must be defined in
  `subject_definitions`, and its meaning must stay identical across all six
  sections. Never leave a dangling label.
- **Speaker IDs** `(S1)`, `(S2)` are assigned once, in order of first actual
  vocal event, and reused everywhere after. Never write `(Sx)` in
  `retention_analysis`.
- **Camera motion** is written as natural English inside the shot — motion type,
  then amplitude and speed only when meaningful — not appended as bare labels.
- `detailed_description` for generation tasks runs **350–500 English words**.
  Dialogue-heavy pieces prioritise fitting the spoken timeline over word count.

## Using reference images (vision)

When reference images are attached, **look at them** and write
`subject_definitions` from what is actually visible — hair colour and length,
garments and their colours, materials, distinguishing props, the specific
architecture and palette of an environment. Generic definitions ("a young
woman") waste the reference; specific ones ("long dark hair, cropped olive
utility jacket, thin silver chain") are what preserve identity across shots.

Map attachments to labels in the order the user presents them, honouring any
explicit assignment they state. An image used **only** to define a character,
outfit, environment or style is cited inside that `<Subject N>` definition and
does **not** get its own `<Picture N>` entry. An image that serves as a concrete
frame anchor — first frame, keyframe, last frame — does get its own
`<Picture N>` entry.

Derive the visual style of the piece from the reference images unless the user
overrides it.

## Sound

H3 generates audio jointly with video, so the audio sections are not decoration
— they materially shape the result.

- `overall_soundscape` — 1–4 sentences, one paragraph: ambience, physical action
  sounds, non-verbal human sounds. Never repeat dialogue, singing, or diegetic
  music here. `N/A` only if the user explicitly wants silence.
- `non_diegetic_music` — 1–3 sentences: instrumentation, tempo, rhythm, dynamic
  change. Describe the *score*, not its emotional function — no "melancholy" or
  "builds tension". Music a character can actually hear (radio, busker, phone)
  is diegetic and belongs in the description body instead. `N/A` if there is no
  score.

## Procedure

1. Determine the mode from what the user supplied.
2. Read the matching reference guide section by section.
3. If reference images are attached, inventory what is visible in each before
   writing anything.
4. Assign labels and speaker IDs, then keep them fixed.
5. Lay the timeline out against the requested duration before writing shots.
6. Emit the sections in the required order, and stop.
